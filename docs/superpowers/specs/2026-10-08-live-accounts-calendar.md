# 独立运行：真实额度与 Google Calendar

用户扩展目标为 Codex 等真实数据及 Google Calendar，并明确要求不依赖电脑运行。验收暂停，先完成开发。电脑仅用于首次授权和通过 USB 导入授权资料。

ESP32 直接通过 HTTPS 连接各服务。Google Calendar 使用 Desktop OAuth 一次性授权获得 refresh token；设备随后自己更新 access token，并只读获取未来七天内最早三条仍未结束的日程。授权范围 calendar.events.readonly。新增日历、日程详情页；主页新增日历入口，保留已认可的待机排版。

Codex 使用官方客户端实际采用的额度后端，显示主窗口/周窗口剩余百分比与重置时间；不把额度百分比换算成 token 数。Claude、Antigravity、Cursor 逐项按本机客户端的实际读取接口适配；客户端内部接口可能变化，获取失败时显示未连接、需重新授权或过期，而非继续伪装真实余额。货币、credits、百分比各自保留单位；未知上限不生成百分比。

授权存储在设备独立 NVS namespace，仅导入工具能读本机账号资料，资料不写源码、公开日志、固件文件或 Git。忘记 Wi-Fi 不清除账号授权；另提供明确的账号清除命令。当前硬件 Flash 未加密，物理读取 Flash 可获取授权资料；不擅自烧写 eFuse。

网络工作线程与 UI 分离，UI 读取受互斥保护的完整快照。断开网络或更新授权后，旧请求不得覆写新状态。请求、JSON 大小、字段类型、UTF-8 长度与数值范围有界；失败保留最近真实数据并标记过期。

日历标题、地点、描述采用包含基础中日韩字形的 14px 字体，限制显示长度并截断长文；不修改或发送日历事件。只读三条事件的必要字段，不把 OAuth token 交给第三方桥接。
